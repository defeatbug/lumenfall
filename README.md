LUMENFALL is a top-down arena survival shooter: guard the last lighthouse against waves of shadows. Survive 10 waves, then endless mode. All sound effects are synthesized, no network needed — just open it in a browser.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in your browser.
